# portvex/homebrew-tap

Homebrew formulae and casks for portvex tools.

| Tool | What it is | Install |
| --- | --- | --- |
| [tuidesk](https://github.com/portvex/tuidesk) | KDE Plasma style desktop that runs inside a terminal (macOS, Linux) | `brew install portvex/tap/tuidesk` |
| [bxplore](https://github.com/portvex/bxplore) | Binary eXplorer: viewer and editor for PE, ELF and Mach-O files (macOS) | `brew install --cask portvex/tap/bxplore` |

## tuidesk

The formula installs the prebuilt executables: the universal one on macOS, the static musl
ones on Linux. It is generated for each release by `cargo xtask dist recipes` in the tuidesk
repository and attached to the release as `tuidesk.rb`.

## bxplore

The cask installs `bxplore.app` from the release's universal DMG (Intel and Apple Silicon)
and links `bxplore` for `bxplore --dump <file>`. bxplore is not notarized, so macOS blocks
the app and the command until you allow it once: open bxplore.app with right click, Open, or
run

    xattr -dr com.apple.quarantine /Applications/bxplore.app

The cask is generated by the release workflow of the bxplore repository from
`packaging/homebrew/bxplore.rb.in` and attached to each release as `bxplore.rb`.
